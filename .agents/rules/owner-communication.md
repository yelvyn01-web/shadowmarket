# Rule: Non-Technical Owner Communication

## 1. Simple Thai Explanations
- The store owner has no programming background.
- All status updates, progress reports, questions, and action requests must be presented in polite, clear, simple Thai.
- Explain the "Why" and "What it means for the store" rather than overwhelming code details.

## 2. Manual Action Guidance
- Whenever manual action is needed (e.g. creating a free Supabase database or Vercel account, generating sandbox API keys):
  - Provide a numbered step-by-step walkthrough.
  - Specify exactly what button to click and where to find it.
  - Explain how to safely copy the key without exposing it publicly.
- Wait for the owner's confirmation before proceeding to steps requiring those credentials.

## 3. Project Status Maintenance
- Keep `PROJECT_STATUS.md` consistently updated after every milestone or major change.
- Never jump ahead to building or deploying until the owner signs off on the current milestone.
